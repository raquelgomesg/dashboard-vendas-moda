# Dashboard de Vendas no Setor de Moda

Este projeto foi criado com Power BI para analisar dados de vendas no setor de moda.

## Métricas principais:
- Receita total
- Quantidade vendida
- Ticket médio
- Receita por categoria
- Evolução da receita no tempo
- Mapa por região

## Como usar
1. Baixe o arquivo `.pbix`
2. Abra no Power BI Desktop (gratuito)
